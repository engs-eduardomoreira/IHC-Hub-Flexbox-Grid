1. O que é o Grid? Colunas e a unidade fr

O Grid é um modelo de layout bidimensional: organiza os elementos em linhas E colunas ao mesmo tempo. O container é o pai com display: grid; e os itens são seus filhos diretos.

As colunas são criadas com grid-template-columns. A unidade fr (fração) divide o espaço livre em partes proporcionais. Abaixo, 1fr 2fr 1fr; quando acabam as colunas, os itens criam novas linhas automaticamente.

2fr

.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

2. repeat() e minmax()

repeat(4, 1fr) equivale a 1fr 1fr 1fr 1fr. Com minmax() e auto-fit, o layout fica responsivo sem media queries (redimensione a janela). É o recurso usado nos cards do hub!

grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));

3. gap e span

O gap cria espaço entre as células. Com grid-column: span 2; o item ocupa 2 colunas e, com grid-row: span 2;, 2 linhas. A altura das linhas é definida com grid-template-rows.

span 2 linhas

.container { gap: 10px; }
.destaque  { grid-column: span 2; }

4. grid-template-areas

Permite "desenhar" o layout com nomes: cada texto entre aspas é uma linha da grade e os itens recebem o nome com grid-area. Para centralizar o conteúdo das células, use place-items: center;.

header
menu
conteúdo
footer

grid-template-columns: 150px 1fr;
grid-template-areas:
  "header   header"
  "menu     conteudo"
  "footer   footer";
.a-header { grid-area: header; }   /* e assim por diante */
